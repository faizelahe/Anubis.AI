# ⚖️ Anubis AI: The Sentinel of Human Intent
**Track:** Humanitarian | **Tech:** IBM Granite 4.0, Featherless.ai, Google NotebookLM

## The Problem
The "Technical Underworld." Entry-level roles now demand 20+ disparate skills (SQL, Python, J2EE, Tableau) before a human is allowed to make a strategic decision. 

## The Solution
Anubis AI is an Agentic Bridge. It uses Sovereign AI to handle the syntax of data cleaning and analysis, allowing humans to focus on the goal, not the gatekeeper.

## SDG Targets
- **Goal 4.4:** Increasing technical/vocational skills for employment.
- **Goal 8.2:** Achieving higher levels of economic productivity through innovation.
